RULES12

A rule must stay correct. Select a component to see its rules.

  1. Do not show code or test counts on the page. The map shows system functions, not code quantity (src/systemap/skill/references/schema.md, Component).
  2. A component must have a function that a reader can identify. A module alone does not identify a component (README, What are a component, a flow, and a sequence?).
  3. Flow lines show relationships. Each flow must have an explanation (src/systemap/skill/references/schema.md, Flow).
  4. The map shows code in the repository. Each module in a component claim must be in the facts. The map is not a plan (src/systemap/check.py, check_entry).
  5. Keep positions in the model. systemap place or a person writes positions. The check rejects layout errors (src/systemap/skill/references/layout.md, Component positions and routes).
  6. The agent writes the model. The check rejects errors. The maintainer examines the model (README, How do you install systemap?).
  7. Make the map with more than one examination. A second examination is necessary (src/systemap/skill/SKILL.md, The loop).
  8. The page has no external file requests or dependencies (src/systemap/page.py, build).
  9. Reject unknown configuration keys. Do not ignore them (src/systemap/config.py, load: 'unknown key').
  10. Each ignored module must have a reason (tests/test_coverage.py: test_ignore_without_reason_is_a_config_error).
  11. check does not use the network. judgement uses the network only with --order-by-drift (src/systemap/drift_order.py, docstring). A different Jev command sends requests only with a key (src/systemap/jev_cli.py, docstring).
  12. Use ASD-STE100 Issue 9 for all names and all text that a person reads (AGENTS.md, Language requirement).
